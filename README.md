# Hero Shooter — Sophia's Scrapyard (3D playable prototype)

Hero Shooter now has a playable **native-resolution WebGL 3D sandbox** featuring **Sophia / Saafiya**, using her approved v3.3 Python VTK geometry and a preserved painted face texture. The original 50 × 28 metre scrapyard environment was created with VTK and has genuine GLB geometry and a 0.5-metre collision grid. Three male looters are optional walking NPCs.

The retired 2D chapter game, directional sprite atlases, character portrait game assets, and old 2D JavaScript runtime have been removed **in this feature branch**. They remain recoverable from Git history. This is a deliberate test-bed, not a complete campaign or a fully rigged final game.

## Try it locally

Requires Node.js 22+, Chrome/Chromium or Firefox with WebGL, and an internet connection for the pinned Three.js 0.180.0 browser import map.

~~~bash
git clone --branch feat/sophia-scrapyard-3d-playable-20261122 https://github.com/cryogenized-spec/Hero-shooter.git
cd Hero-shooter
npm run check
npm test
npm run build
npm run preview
~~~

Visit **http://localhost:4173/**. This is the **main page**, not a hidden testing route. Launching \`index.html\` directly as \`file://\` is unsupported; run the server. If the Sophia GLB has not yet been published on the branch by the rendering workflow, the entry displays a clear loading error.

### Controls

- **W/A/S/D**, or arrow keys: walk relative to the camera
- **Shift**: run
- **Space**: jump (simple gravity; no advanced physical interactions)
- **Mouse drag / wheel**: orbit and zoom
- **V**: third-person versus overhead camera
- **J**: throw a harmless test stone with a visual flight arc
- **F**: raise Sophia's equipped prop arm to an aim pose
- **N**: show/hide the three male looter NPCs
- **R**: respawn at the south gate
- **H**: show/hide controls
- Touchscreen users have a compact on-screen movement/action pad

## Included genuine 3D assets

- \`public/play/assets/procedural/sophia/sophia_v33_articulated.glb\` — **1.72 m**, approved model with 2048² painted face, procedural rigid limbs and original chrome prop, generated by \`tools/render/export_sophia_articulated.py\`.
- \`public/play/assets/procedural/scrapyard/scrapyard_arena.glb\` — 50 × 28 metre scrapyard with central container, tower, wrecks, barricades, targets and fencing.
- \`public/play/assets/procedural/scrapyard/arena_navgrid.json\` — 100 × 56 walkability grid with conservative obstacle inflation.
- Three articulated adult male looter GLBs and separate brick/stone/knife GLBs, preserved for NPC experimentation.

### Limitations

This is an **experimental playable sandbox**. Rigid-part procedural movement is not a skinned skeletal rig, and boots/arms may intersect clothing during motion. Ground-level obstacle checks use the authored grid; stairs, elevated platforms and exact mesh collision are not navigable yet. NPCs are wandering demonstrations, not full adversarial AI. Test stones and aiming have no combat damage. Rendering uses a device-pixel ratio capped at 1.6 to help midrange GPUs, but **does not enlarge 2D sprites**.

GitHub pull request for this sandbox is based on the existing 3D looter/scrapyard feature branch so that it can be reviewed without overwriting concurrent project work.
